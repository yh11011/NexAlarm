# Security policy

## Supported versions

NexAlarm is currently a beta project. Security fixes target the latest commit on `main`; no released version has a long-term support commitment.

## Reporting a vulnerability

Please use GitHub's **Security → Report a vulnerability** private-reporting flow. If private reporting is unavailable, contact the repository owner through the contact method on their GitHub profile before publishing details.

Include the affected commit/version, Android version, reproduction steps, impact, and any logs with tokens or personal data removed. Do not open a public issue for an unpatched secret exposure, authentication bypass, unsafe deep link, or signing-key concern.

Never include real credentials, keystores, JWTs, alarm contents, or Firebase private keys in a report. Receipt and remediation times are not guaranteed while the project is in beta.
