Implemented in source

Alarm reliability path

可使用精確鬧鐘時採 setAlarmClock()；Android 12+ 未授權時降級為非精確的 setAndAllowWhileIdle()。

Schedule groups

一次性與週期鬧鐘可用資料夾／群組整理，並支援群組切換、貪睡、音量與僅震動。

System integration

包含開機重新排程、前景響鈴服務、全螢幕通知、Meeting Mode Quick Settings tile 與 deep links。

Verification boundaries

Repository verification

CI 已設定執行 Android lint、JVM unit tests、debug build 與 Gradle Wrapper validation。程式庫定義了 14 個 instrumented reliability scenarios；PR run 結果才是該 commit 的驗證證據。

Not yet established

目前 commit 的完整 14 場景通過報告、多裝置／OEM matrix、正式 signed beta、Google Play review，以及所有外部服務的 end-to-end 驗證。

AI-assisted, human-verified

AI 工具用於加速實作、review、文件與 debugging；輸出不被預設為正確。可驗證結果來自程式碼、lint、tests、CI 與需要時的實體裝置測試，未驗證部分則明確保留。
