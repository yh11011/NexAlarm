# NexAlarm 工程進度（2026-08-13）

## 本輪目標

把 NexAlarm 從一般鬧鐘提升為可處理複雜行程的工具，同時改善主畫面、行程群組、主題可讀性與桌面 Widget。

## 已完成

### 複雜行程與可靠性

- 將資料夾升級為「行程群組」，群組開關會實際排程或取消群組內鬧鐘。
- 保留每個鬧鐘自己的啟用狀態；重新開啟群組時只恢復原本啟用的鬧鐘。
- 開機重排、鬧鐘觸發與首頁下一響均尊重群組啟用狀態。
- 群組內支援重複鬧鐘，不再將所有群組鬧鐘誤判為每日重複。
- 新增鬧鐘可靠性檢查卡與 30 秒測試鬧鐘入口。

### UI 與視覺系統

- 建立共用頂部列、指標卡與圖示徽章，統一主要畫面層級。
- 行程群組改用 Material 線性圖示，並相容既有 emoji 資料。
- 主題收斂為兩個可用模式：「日間專注」與「夜間模式」。
- 夜間模式保留炭黑背景並使用天空藍互動主色。
- 舊主題 ID 會安全映射至新模式；舊 `night_neon` 會遷移到夜間模式。
- 主題文字、邊框與卡片色票加入 WCAG 對比測試。

### 桌面 Widget

- 新增 2×1 時鐘 Widget、Manifest 註冊、背景與尺寸設定。
- Widget 使用系統 `TextClock` 自行更新，整張卡片皆可點擊開啟 App。
- Widget 僅允許水平調整尺寸，避免垂直拉伸破壞排版。

### 工具與文件

- 圖示產生腳本改用命令列參數，不再依賴個人電腦絕對路徑。
- MCP 說明與專案文件移除特定 AI 工具名稱及本機絕對路徑。

## 驗證狀態

- JVM 單元測試：已通過。
- Debug APK：已成功建置。

- 主題實機驗證：設定頁只顯示「日間專注」與「夜間模式」，夜間模式選取狀態正確。
